# UC-VehicleTampering

A simple script to enhance roleplay with vehicles, giving players the ability to tamper with vehicles

The main intention of this script was to make it super easy for server owners/developers to add their own tampering options as easily as possible!
Adding a new table into the config allows you to run your own function and also handles the target, state bags(Syncing), item removal, and checking for you

## ⚙️ Install

- Drag and drop the images from the INSTALL/images folder into your inventory images folder
- Add the items into your inventory system also inside the INSTALL folder
- add to your server.cfg
